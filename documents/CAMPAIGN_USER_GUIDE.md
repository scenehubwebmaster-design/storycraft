# D&D Campaign System - User Guide

## 🎮 Getting Started with D&D Campaigns in StoryCraft

### Step 1: Create D&D Characters

Before starting a campaign, you need D&D characters!

1. Go to **Characters** page
2. Click **New Character**
3. Select **D&D 5E Character** generation
4. Choose class, species, background, alignment
5. Generate narrative and portrait
6. Save character

Repeat for all party members (recommended: 2-6 characters).

---

### Step 2: Start a Chat Session

1. Go to **DMChat** page
2. In the left sidebar, enter a session title (e.g., "Lost Mines Adventure")
3. Click **Begin Session**
4. Your chat session is now active!

---

### Step 3: Create Campaign

1. Click **Setup D&D Campaign** button (left sidebar)
2. **Campaign Setup Wizard** opens with 3 steps:

#### Step 1: Campaign Details

- **Title**: Name your adventure (e.g., "The Lost Mines of Phandelver")
- **Description**: Brief story overview
- **Type**: Choose campaign length
  - **One-Shot**: Single session (2-4 hours)
  - **Short Adventure**: Multi-session (3-6 sessions)
  - **Epic Campaign**: Long-running (20+ sessions)
- **Setting**: Forgotten Realms, Eberron, Homebrew, etc.
- **Difficulty**: Easy, Normal, Hard, Deadly
- **Starting Level**: 1-20

#### Step 2: Select Party

- See all your D&D characters with portraits
- Click to select party members
- Shows character stats (HP, AC)
- Can select multiple characters

#### Step 3: Review & Create

- Review campaign details
- See selected party members
- Click **Create Campaign**

✅ Campaign created! Right panel now shows **Party Panel**.

---

### Step 4: Understanding the UI

#### Left Panel (Campaign Controls)

- **Campaign Manager** (top)
  - Campaign title and description
  - Current level badge
  - Scene type badge (💬 Roleplay, ⚔️ Combat, etc.)
  - **XP Progress Bar**
    - Shows XP to next level
    - Total XP displayed
  - **Award XP** button
  - Party member list with HP
- **RAG Context** (middle)
  - Enable/disable AI knowledge retrieval
  - Adjust context depth
- **Voice Narration** (bottom)
  - TTS controls
  - Voice selection

#### Center Panel (Chat)

- **Message Input** (top)
  - Type your actions/questions
  - Send to AI DM
- **Messages** (bottom, scrollable)
  - Your messages
  - AI DM responses
  - Voice narration option per message

#### Right Panel (Party/Combat)

- **Tab Buttons** (top)
  - **Party**: View party status
  - **Initiative**: Combat turn order (active during combat)
  - **Combat**: Quick actions (active during combat)
- **Panel Content** (middle, scrollable)
- **🎲 Roll Dice** button (bottom)

---

### Step 5: Playing the Game

#### Awarding XP

1. After encounters or milestones, click **Award XP**
2. Enter XP amount (or use quick presets)
3. Add optional reason (e.g., "Defeated goblin ambush")
4. Click **Award XP**
5. Progress bar updates
6. **Automatic level-up** when threshold reached!

**Quick XP Presets**:

- Easy: 50 XP
- Medium: 100 XP
- Hard: 200 XP
- Deadly: 400 XP

#### Party Panel

Shows real-time party status:

- **Portrait** images
- **Name** and class/species/level
- **HP Bar** (color-coded)
  - Green: >75% HP
  - Blue: 50-75% HP
  - Yellow: 25-50% HP
  - Red: <25% HP
- **Quick Stats**:
  - 🛡️ AC (Armor Class)
  - ⚡ Initiative modifier
  - 🧠 Spell DC (if caster)
- **Active Conditions** (if any)
  - Poisoned, Stunned, etc.
- **Status Badge** (if not active)
  - Unconscious, Dead

#### Dice Roller

Click **🎲 Roll Dice** to open:

1. Select dice type (d4, d6, d8, d10, d12, d20, d100)
2. Choose number of dice (1-20)
3. Add modifier (+/- any number)
4. Click **Roll**
5. See animated result with breakdown
6. Critical hit/fail detection for d20
7. View roll history

**Quick Roll Buttons**:

- D20 (simple check)
- D20 + 5 (check with modifier)
- 2D6 (damage)
- 1D8 + 3 (weapon damage)
- Fireball (8D6)

---

### Step 6: Combat

#### Starting Combat

1. When combat begins, switch to **Initiative** tab
2. Click **Roll Initiative & Start Combat**
3. **Initiative Dialog** opens:
   - Shows all party members
   - Each has roll button (🎲)
   - Clicking rolls d20 + initiative modifier
   - Can manually edit roll
4. Click **Start Combat**

#### During Combat

Initiative Tracker shows:

- **Turn order** (highest to lowest)
- **Current turn** highlighted
- **Round counter**
- **HP bars** for each combatant
- **Active conditions**
- **Next Turn** button

#### Combat Actions

Switch to **Combat** tab:

1. Select character from dropdown
2. **Apply Damage**:
   - Enter damage amount
   - Click **Damage**
   - HP updates instantly
   - Status changes if unconscious
3. **Apply Healing**:
   - Enter healing amount
   - Click **Heal**
   - HP updates instantly
4. **Quick Actions**:
   - Attack, Cast Spell, Dash, Dodge, Help, Search
   - Sends structured action to AI DM
5. **Common Spells**:
   - Fireball (sets 8d6 damage)
   - Cure Wounds (sets healing amount)

#### Ending Combat

1. Click **End Combat** in Initiative Tracker
2. Initiative order clears
3. Returns to **Party** tab
4. Scene type changes to 💬 Roleplay

---

### Step 7: Tracking Progress

#### XP & Leveling

- XP awards are logged in session notes
- Total XP tracked across sessions
- Level-up happens automatically
- D&D 5e official XP thresholds used

**XP Thresholds**:

- Level 2: 300 XP
- Level 3: 900 XP
- Level 4: 2,700 XP
- Level 5: 6,500 XP
- (and so on to Level 20: 355,000 XP)

#### Campaign State

Campaign Manager tracks:

- Current level
- Scene type (roleplay, combat, exploration, etc.)
- Current location
- Party HP status
- Session notes (includes XP awards)

## 💡 Tips & Best Practices

### For Players

1. **Award XP consistently** after encounters
2. **Track HP carefully** during combat
3. **Use quick rolls** for common checks
4. **Switch tabs** as combat starts/ends
5. **Check Party Panel** regularly for status

### For DMs

1. **Use scene types** to signal gameplay mode
2. **Award XP generously** for creative solutions
3. **Track conditions** for ongoing effects
4. **Roll initiative** when combat is certain
5. **Use dice roller** for transparent rolls

### Pro Tips

- **Portraits help**: Character portraits make party management easier
- **Quick presets**: Use XP/dice presets for speed
- **Real-time updates**: Party panel auto-refreshes HP
- **Initiative auto-sorts**: Don't worry about order
- **Level up alerts**: Watch for automatic level increases

## 🎲 Quick Reference

### Scene Types

- 💬 **Roleplay**: Social interactions, dialogue
- ⚔️ **Combat**: Battle, initiative tracking
- 🗺️ **Exploration**: Dungeon crawling, discovery
- 🔥 **Rest**: Short/long rest, recovery
- 💰 **Shop**: Buying/selling equipment

### Combat Order

1. Roll initiative (highest goes first)
2. Take turn (action, bonus action, movement)
3. Click "Next Turn"
4. Repeat until combat ends

### Dice Types

- **d4**: Dagger damage, healing
- **d6**: Shortsword, Fireball
- **d8**: Longsword, Cure Wounds
- **d10**: Crossbow, cantrips
- **d12**: Greataxe
- **d20**: Ability checks, attacks, saves
- **d100**: Percentile rolls

## ❓ Troubleshooting

### Campaign Won't Create

- Ensure you have a chat session active
- Check that characters are D&D type (not regular characters)
- Try refreshing the page

### HP Not Updating

- Wait 5 seconds (auto-refresh interval)
- Manually switch tabs to force refresh
- Check network console for errors

### XP Not Awarding

- Verify campaign is active
- Check XP amount is valid number
- Ensure campaign hasn't reached level 20

### Initiative Won't Start

- Make sure party has members
- Check that all members have initiative modifiers
- Verify campaign is in correct scene type
