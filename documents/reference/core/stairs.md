# Stairs (d20)

| d20 | Result |
|:---:|---|
| 1–4 | **Down 1 level → chamber** |
| 5–8 | **Down 1 level → 20-ft passage** |
| 9 | **Down 2 levels → chamber** |
| 10 | **Down 2 levels → 20-ft passage** |
| 11 | **Down 3 levels → chamber** |
| 12 | **Down 3 levels → 20-ft passage** |
| 13 | **Up 1 level → chamber** |
| 14 | **Up 1 level → 20-ft passage** |
| 15 | **Up** to a **dead end** |
| 16 | **Down** to a **dead end** |
| 17 | **Chimney up 1** → 20-ft passage |
| 18 | **Chimney up 2** → 20-ft passage |
| 19 | **Shaft down 1** → chamber (elevator optional) |
| 20 | **Shaft up 1 → chamber** **and** **down 1 → chamber** |
