# Passage (d20)

| d20 | Result |
|:---:|---|
| 1–2 | Straight **30 ft**; **no** doors or side corridors |
| 3 | Straight **20 ft**; **door right**; then **10 ft** straight |
| 4 | Straight **20 ft**; **door left**; then **10 ft** straight |
| 5 | Straight **20 ft**; ends at a **door** |
| 6–7 | Straight **20 ft**; **side corridor right**; then **10 ft** straight |
| 8–9 | Straight **20 ft**; **side corridor left**; then **10 ft** straight |
| 10 | Straight **20 ft**; **dead end** (10% chance **secret door**) |
| 11–12 | Straight **20 ft**; **turns left**, continues **10 ft** |
| 13–14 | Straight **20 ft**; **turns right**, continues **10 ft** |
| 15–19 | **Chamber** (roll on Chamber) |
| 20 | **Stairs** (roll on Stairs)* |

\* If you don’t want multiple levels, reroll or treat stairs as an alternate entrance/feature.
