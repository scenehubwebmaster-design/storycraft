## Moral Quandaries

```table
| d20 | Quandary | Prompt |
|-----|----------|--------|
| 1-3 | Ally | Two essential allies refuse to work together |
| 4-6 | Friend | A beloved NPC demands the hard path |
| 7-12 | Honor | Oath/code conflicts with the clear solution |
| 13-16 | Rescue | Save innocents or catch the villain |
| 17-20 | Respect | Two respected allies disagree; pick one |
```

## Twists

```table
| d10 | Twist |
|-----|-------|
| 1 | A rival group races toward the same goal |
| 2 | Party must protect a noncombatant |
| 3 | Do not kill the villain (but they can kill you) |
| 4 | Hard time limit |
| 5 | False / noisy intel |
| 6 | Prophecy fulfilled or prevented |
| 7 | Two goals; only one is possible |
| 8 | Success secretly aids the villain |
| 9 | Must cooperate with a known enemy |
| 10 | Geas or magical compulsion |
```
