# Location-Based Adventures

Design sites—dungeons, wildernesses, districts—then **key** encounters to spaces that invite decisions.

<!-- chunk:start -->
## Party Goals (Location-Based)

Use these to frame purpose and rewards.

```table
| d20 | Dungeon Goals |
|-----|---------------|
| 1 | Stop dungeon denizens from raiding the surface |
| 2 | Foil a villain’s scheme |
| 3 | Destroy a magical threat inside |
| 4 | Acquire treasure |
| 5 | Find a particular item for a purpose |
| 6 | Retrieve a stolen item hidden here |
| 7 | Find information for a special purpose |
| 8 | Rescue a captive |
| 9 | Learn the fate of a prior party |
| 10 | Find an NPC missing in the area |
| 11 | Slay a powerful monster |
| 12 | Uncover the nature/origin of a phenomenon |
| 13 | Pursue fleeing foes |
| 14 | Escape captivity within the dungeon |
| 15 | Clear a ruin for reoccupation |
| 16 | Learn why a villain is interested here |
| 17 | Win a bet / rite of passage by surviving |
| 18 | Parley with a villain in the dungeon |
| 19 | Hide from an external threat |
| 20 | Roll twice, ignoring 20 |
```
<!-- chunk:end -->
